Syte deployment API

Version __VERSION__. The API supports project workspaces, file operations, deployments, previews, and domain configuration. AI, model, provider, and gateway endpoints are not part of this installation.

Health and server

GET /api/health returns service health. GET /api/system returns server identity and workspace information.

Projects

GET /api/projects, POST /api/projects, GET /api/projects/{project_id}, PUT /api/projects/{project_id}, and DELETE /api/projects/{project_id} manage deployment projects.

Workspace API

Token-authenticated endpoints under /api/workspace_*, /api/read_file, /api/write_file, /api/upload_file, and /api/execute_command manage files and commands inside a project workspace.

Deployment controls

Use POST /api/issue_deploy, /api/start_service, /api/stop_service, /api/start_preview, and /api/stop_preview with a project UUID.
