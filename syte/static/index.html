HTTP Redirects Guide

            
Understanding status codes, wildcards, parameters, and matching order.

          

        

        
      

      

        

          
 Status Codes Overview

          
    
            
  • 301 Moved Permanently: Use when a URL is permanently moved. Search engines transfer SEO authority. Browsers cache aggressively.
    • 
            
  • 302 Found (Temporary): Use for temporary promotions or maintenance. Browsers do not cache indefinitely.
    • 
            
  • 307 Temporary Redirect: Preserves the HTTP method. A POST request to the source URL remains a POST to the destination.
    • 
            
  • 308 Permanent Redirect: Permanent redirect that guarantees the HTTP method (POST/PUT/DELETE) is preserved.
    • 
          

        


        

          
 Wildcards & Named Parameters

          
    
            
  • Wildcards (*): /blog/* ➔ /articles/* matches /blog/post-1 and redirects to /articles/post-1.
    • 
            
  • Named Parameters (:param): /docs/:version/:topic ➔ /documentation/:version/:topic captures specific path segments.
    • 
          

        


        

          
 Priority & Loop Protection

          
    
            
  • Top-to-Bottom Evaluation: Rules are evaluated sequentially from top to bottom. Place specific rules above broad wildcard rules.
    • 
            
  • Loop Prevention: The system detects infinite bounce loops (e.g. /a ➔ /b and /b ➔ /a) and alerts before saving.
