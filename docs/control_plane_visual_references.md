# Control Plane visual reference map

## Primary authentication reference

- **Login & Signup Page – AI Website**, RahMan, Dribbble: https://dribbble.com/shots/27139066-Login-Signup-Page-AI-Website
- Observed composition: a soft light-grey outer canvas, a large rounded white two-column card, an editorial/illustrative left panel, and a narrow high-clarity authentication form on the right.
- Signature details to adapt: a compact wordmark, monochrome micro-labels, thin neutral input outlines, a full-width black primary button, small social/alternative action rows, serif-led headline hierarchy, and generous white space.
- Functional adaptation: the right form remains the real workspace-password login. The left illustration becomes an abstract project/control-plane preview with no fake data or inaccessible functionality.

## Hosting-workspace reference direction

- Dribbble search results were reviewed for server settings, server dashboard, and terminal dashboard patterns. The selected visual language is the dark, graphite server-workspace approach: muted side rail, dense but calm information blocks, thin grey boundaries, a dominant terminal/primary surface, and restrained status color.
- The workspace will retain actual sections only: Console, Terminal, Files, Startup, Network, and Access. Each will be recast using the same visual system rather than adding decorative dashboard cards without live data.

## Responsive interpretation

- Mobile: the authentication card becomes a single white form surface after the editorial panel; hosting screens become stacked block surfaces with a bottom task bar.
- Desktop: the authentication reference remains a centered split card; hosting screens use a narrow rail and asymmetric content grid with the live operational surface first.

## Constraints

- Dribbble is used as a layout and visual reference. The implementation uses original code, real Syte data/actions, and does not copy image assets, trademarks, or inaccessible functionality.
